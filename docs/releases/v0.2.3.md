# Doc Media Toolkit 0.2.3

Version 0.2.3 is a source security and portability release. It does not publish
prebuilt macOS or Windows packages.

## Changes

- Normalizes OOXML relationship separators before resolving document media,
  preventing Windows path traversal through crafted DOCX/XLSX relationships.
- Runs LibreOffice with an argument list instead of a Windows batch shell.
- Forces Office/WPS COM automation to disable macros and refuses macro-enabled
  documents when that safety setting cannot be confirmed.
- Applies PDF page-size and pixel budgets before rendering or watermarking, and
  retains pypdf's array-stream decompression limit.
- Pins CI bootstrap tools, keeps generated dependency exports out of Git, and
  repairs source-install and packaging documentation.
- Fails early when the source-pinned FFmpeg toolchain lacks
  `pkg-config`/`pkgconf`, then records the selected tool explicitly.
- Redacts build-host project, home, temporary, and runner paths from generated
  release-audit reports while retaining portable artifact labels and hashes.

## Compatibility and release boundary

Video and image library schemas remain at version 1, so no migration is needed.
Local ad-hoc DMGs are test candidates only. Public prebuilt packages remain
blocked until platform signing, notarization where applicable, target-host
malware scanning, native inventory, artifact SBOM, license evidence, and the
public-binary gate pass for the exact artifacts.
