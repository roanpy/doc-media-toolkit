## FFmpeg evidence

- Both macOS candidates bundle Homebrew FFmpeg 8.1.2 with `--enable-gpl` and
  `--enable-version3`. The arm64 build uses the Apple Silicon Homebrew prefix; the
  Intel build uses the Intel Homebrew prefix.
- The Windows candidate bundles the Gyan essentials FFmpeg
  `8.1.2-essentials_build-www.gyan.dev`, configured as a static GPLv3 build with
  `--enable-gpl` and `--enable-version3`.
- License text is present inside all three candidates. License text alone is not
  corresponding-source delivery for the exact bundled binaries.

## Decision

The GitHub Release was returned to Draft and its public package URLs were verified
to be inaccessible. The tag and source remain available for review. The candidates
must not be republished or silently replaced under the same public version until the
public-binary evidence gate passes.

Future Windows candidates use an onedir portable ZIP instead of one-file packaging.
Future macOS and Windows candidates build FFmpeg 8.1.2 and x264 from the pinned
sources in `scripts/build_ffmpeg_runtime.sh`; each build emits the exact source
archives, build script, configuration, toolchain record, licenses, and hashes as a
same-Release corresponding-source asset. The withdrawn Homebrew/Gyan binaries are
not reused.
The manual build workflow no longer has permission or code to publish a GitHub
Release; publication is a separate owner-reviewed action after evidence validation.
