# Doc Media Toolkit 0.2.2

Version 0.2.2 is a source-only security and release-integrity update. It includes
all hardening merged after the 0.2.1 tag and does not publish DMG or Windows
binary packages.

## Changes

- Rejects unsafe entity declarations while parsing user-supplied Office XML.
- Strengthens the public-binary evidence gate by validating and binding SBOM,
  native-inventory, malware-scan, and bundled-FFmpeg source records to the exact
  artifact.
- Renames the Python distribution to `doc-media-toolkit` to avoid collision with
  an unrelated project already published as `pptx-tools`; the `pptx_tools`
  import package and `pptx-tools` / `pptx-tools-gui` commands remain unchanged.
- Installs CI and candidate-build dependencies from `uv.lock` with hashes and
  keeps every GitHub Action pinned to a full commit SHA.
- Includes the generated DOCX/XLSX fixtures needed by the tests in the Python
  source distribution.
- Supports a Git-ignored local denylist for project-specific confidential names
  without echoing matched private text in scan output.
- Adds Dependabot maintenance and explicit repository rules for AI-assisted
  contributions without enabling automatic Actions runs.

## Compatibility and release boundary

Video and image library schemas remain at version 1, so no migration is needed
from 0.2.0 or 0.2.1. Public prebuilt packages remain blocked until platform
signing, macOS notarization, target-host malware scanning, native inventory,
artifact SBOM, and the public-binary evidence gate pass for the exact artifacts.
