# Doc Media Toolkit 0.2.4

发布日期：2026-08-22

0.2.4 是一次发布收口、跨平台稳定性和资源库体验更新；源码继续以 MIT 许可公开，
macOS/Windows 安装包仍属于候选产物，未完成所有者签名、公证或 Authenticode 前不作为
公开正式 Release 发布。

## 主要变化

- PPTX 视频压缩、水印替换与高清回填新增播放结构失败关闭校验：幻灯片 XML 必须逐字
  保持，关系 ID 和类型必须不变；自动播放、静音、音量、循环等设置不会因媒体重命名
  或 WMV/AVI 转 MP4 而静默丢失。
- 完整视频库跨机器复制后，只有时间戳变化的文件显示为“待校验”；SHA-256 一致时可
  一次刷新为正常，真正的大小或内容变化仍按异常处理。
- 切换复制的视频库时可识别唯一内层库，并清理旧筛选、详情抽屉和状态残留。
- 视频库空状态直接提供“导入视频”入口；压缩页缩短副标题并明确“目标容量用 GPU”。
- 视频库、图片库、设置和相关对话框完成中英文覆盖并继续跟随系统语言。
- CI 在 Python 3.10、3.12、3.13、macOS 与 Windows 上固定必要运行时边界，并限制为
  `contents: read` 权限。

## 验证边界

- PPTX 压缩、水印、视频库及主要文档兼容路径由隔离测试、真实 FFmpeg E2E、静态检查
  和公开安全扫描覆盖。
- 图片库仍是附加能力，验证深度低于 PPTX/视频核心路径。
- 标准轻量包内置固定源码构建的 FFmpeg；Office/WPS/LibreOffice/Keynote/Pages 和
  Poppler 仍按功能作为外部运行时。
- 未签名候选包只用于内部或测试验证，不能替代正式签名和目标平台恶意软件扫描。
