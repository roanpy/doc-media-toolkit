# Doc Media Toolkit 0.2.1

Version 0.2.1 is the release-compliance patch following the public 0.2.0 source
tag. It does not reuse or relabel the withdrawn 0.2.0 binary candidates.

## Changes

- Builds bundled FFmpeg 8.1.2, x264, and zlib from SHA-256-pinned source and
  emits the matching corresponding-source archive, licenses, configuration, and
  hashes.
- Uses a manual, read-only candidate workflow with no GitHub Release publishing
  job and a portable onedir Windows layout.
- Adds fail-closed public-binary evidence checks for trusted platform signing,
  macOS notarization, malware scanning, SBOM, native inventory, and bundled
  FFmpeg source delivery; SBOM/native-inventory sidecars are bound to the exact
  package SHA-256.
- Adds local target-host helpers for native inventories and ClamAV/Windows
  Defender reports; missing scanners remain `unavailable` rather than clean.
- Keeps LibreOffice and other office engines external in the standard package;
  the explicit complete LibreOffice offline build remains private/internal until
  its separate redistribution obligations are verified.
- Adds bilingual installation, licensing, release, architecture, and in-app help
  guidance.

## Compatibility and safety

Video and image library schemas remain at version 1, so no library migration is
required from 0.2.0. Source files are still preserved by default, and managed
cleanup remains recoverable.

The source patch can be reviewed and merged independently. macOS and Windows
binary packages must remain private until signing, notarization where applicable,
target-host malware scanning, native inventory, and the public-binary audit all
pass for the exact artifacts.
