# Security Policy / 安全策略

## Supported versions / 支持版本

Security fixes are made on the latest `main` branch and the newest published release. Older releases may be asked to upgrade before a fix is provided.

安全修复面向最新 `main` 分支和最新正式版本；旧版本可能需要先升级。

## Reporting a vulnerability / 报告漏洞

Do **not** open a public issue. Use **Report a vulnerability** at <https://github.com/roanpy/doc-media-toolkit/security/advisories/new> to create a private report. If private vulnerability reporting is unavailable, contact the maintainer through the contact method listed on the maintainer's GitHub profile and include only a request for a private channel—do not include exploit details publicly.

**不要提交公开 Issue。** 请在仓库的 Security 页面使用 **Report a vulnerability** 私下报告。如果该入口尚未启用，请通过维护者 GitHub 主页公开列出的联系方式请求建立私密沟通渠道，不要在公开内容中附带漏洞细节。

Include the affected version, platform, impact, reproduction steps, and a minimal sanitized sample when safe. Never include real credentials or confidential documents.

请提供受影响版本、平台、影响、复现步骤，以及安全时可提供的最小脱敏样例；不要提交真实凭据或机密文档。

The maintainer will acknowledge a complete report as soon as practical, coordinate validation and remediation privately, and publish credit only with the reporter's consent.

维护者会尽快确认完整报告，私下协调核实和修复，并仅在报告者同意时公开致谢。
